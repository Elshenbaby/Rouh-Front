# Frontend skills

Before each frontend task, select the relevant installed skills and read their `SKILL.md` files. Use only skills that apply to the task, and avoid adding dependencies solely to use a skill.

- For substantial new UI pages, redesigns, or visual changes, use `ui-ux-pro-max` and `frontend-design`.
- For React or Next.js component implementation and performance optimization, use `vercel-react-best-practices`.
- For reusable component architecture and major component refactoring, use `vercel-composition-patterns`.
- For accessibility and usability reviews, use `web-design-guidelines`.
- If the project uses shadcn/ui, use `shadcn` when creating or editing its components.
- For browser interaction and responsive layout testing, use `webapp-testing` when practical.

Preserve existing project functionality. At the end of each frontend task, briefly list the skills you actually used and what you verified.
